## Getting Started

### First Launch
When you first open OmniCalculator, you'll see the basic calculator interface with:
- A display area showing "0"
- Number buttons (0-9)
- Operation buttons (+, -, ×, ÷)
- Special buttons (AC, =, ., %)
- Bottom navigation bar

### Navigation
The app has four main sections accessible from the bottom navigation:
- **Calculator** 🧮: Main calculation interface
- **History** 📜: View past calculations
- **Base** 🔢: Convert between number bases
- **Settings** ⚙️: Configure app preferences

## Basic Calculator

### Performing Simple Calculations

1. **Addition Example (15 + 7)**:
   - Tap `1`, `5` → Display shows "15"
   - Tap `+` → Display keeps showing "15"
   - Tap `7` → Display shows "7"
   - Tap `=` → Display shows "22"

2. **Subtraction Example (30 - 12)**:
   - Tap `3`, `0` → Display shows "30"
   - Tap `-` → Display keeps showing "30"
   - Tap `1`, `2` → Display shows "12"
   - Tap `=` → Display shows "18"

3. **Multiplication Example (8 × 6)**:
   - Tap `8` → Display shows "8"
   - Tap `×` → Display keeps showing "8"
   - Tap `6` → Display shows "6"
   - Tap `=` → Display shows "48"

4. **Division Example (100 ÷ 4)**:
   - Tap `1`, `0`, `0` → Display shows "100"
   - Tap `÷` → Display keeps showing "100"
   - Tap `4` → Display shows "4"
   - Tap `=` → Display shows "25"

### Decimal Numbers

To use decimal numbers:
1. Enter the whole number part
2. Tap `.` (decimal point)
3. Enter the fractional part
4. Continue with operations

**Example: 3.5 + 2.1**
- Tap `3`, `.`, `5`, `+`, `2`, `.`, `1`, `=`
- Result: 5.6

### Percentage Calculations

Calculate percentages easily:

**Example: What is 15% of 200?**
1. Tap `2`, `0`, `0` → Display shows "200"
2. Tap `%` → Prepares for percentage
3. Tap `1`, `5` → Display shows "15"
4. Tap `=` → Display shows "30"

### Clear Function

- **AC (All Clear)**: Resets everything to "0"
  - Use when starting a new calculation
  - Clears any pending operations

## Scientific Calculator

### Switching to Scientific Mode

1. Ensure you're on the Calculator screen
2. Look for the mode toggle chips at the top
3. Tap **"Scientific"** to switch modes

### Scientific Mode Features

The scientific calculator adds several rows of functions above the number pad:

#### Memory Functions (Top Row)
- **M+**: Add current display value to memory
- **M-**: Subtract current display value from memory
- **MR**: Recall (display) the value stored in memory
- **MC**: Clear memory (reset to 0)

**Memory Example**:
1. Calculate `5 + 5 =` → Result: 10
2. Tap `M+` → 10 stored in memory
3. Calculate `3 × 4 =` → Result: 12
4. Tap `M+` → Memory now contains 22 (10 + 12)
5. Tap `MR` → Display shows 22

#### Trigonometric Functions (Second Row)
- **sin**: Sine function (input in degrees)
- **cos**: Cosine function (input in degrees)
- **tan**: Tangent function (input in degrees)
- **log**: Base-10 logarithm
- **ln**: Natural logarithm (base e)

**Trigonometry Example (sin 30°)**:
1. Tap `3`, `0` → Display shows "30"
2. Tap `sin` → Display shows "0.5"

**Logarithm Example (log 100)**:
1. Tap `1`, `0`, `0` → Display shows "100"
2. Tap `log` → Display shows "2"

#### Power Functions (Third Row)
- **√**: Square root
- **x^y**: Exponentiation (raise x to power y)

**Square Root Example (√16)**:
1. Tap `1`, `6` → Display shows "16"
2. Tap `√` → Display shows "4"

**Power Example (2^8)**:
1. Tap `2` → Display shows "2"
2. Tap `x^y` → Prepares for exponent
3. Tap `8` → Display shows "8"
4. Tap `=` → Display shows "256"

## Calculation History

### Viewing History

1. Tap the **History** tab in the bottom navigation
2. See all your recent calculations in chronological order (newest first)
3. Each entry shows:
   - The expression (e.g., "5 + 3")
   - The result (e.g., "= 8")
   - The time of calculation

### Using History

**Reuse a Result**:
1. Tap any history card
2. The result automatically loads into the calculator
3. You're taken back to the Calculator screen
4. Continue calculating with that value

**Clear History**:
1. In the History screen
2. Tap the trash can icon (🗑️) in the top right
3. All history is cleared

### History Limits

- The app stores up to 50 calculations
- Oldest calculations are automatically removed when limit is reached
- History persists only during the app session (not saved permanently)

## Base Conversion

### Understanding Number Bases

- **Decimal (DEC)**: Base 10 - normal counting (0-9)
- **Binary (BIN)**: Base 2 - computer language (0-1)
- **Hexadecimal (HEX)**: Base 16 - programming (0-9, A-F)
- **Octal (OCT)**: Base 8 - legacy systems (0-7)

### Converting Numbers

1. Go to the **Base** tab in bottom navigation
2. Enter a number in the Calculator screen first
3. Return to the Base screen
4. The current number is shown in the active base
5. Tap any other base card to convert

**Example: Convert 255 (decimal) to other bases**:
1. In Calculator, enter `2`, `5`, `5`
2. Go to **Base** tab
3. Decimal card shows "255" (selected)
4. Tap **Binary** card → Shows "11111111"
5. Tap **Hexadecimal** card → Shows "FF"
6. Tap **Octal** card → Shows "377"

### Use Cases

- **Binary**: Understanding computer memory and operations
- **Hexadecimal**: Programming (colors, memory addresses)
- **Octal**: File permissions in Unix/Linux systems
- **Decimal**: Everyday numbers

## Tips & Tricks

### Efficiency Tips

1. **Quick Clear**: Double-tap AC to ensure everything is reset
2. **Chain Calculations**: After pressing `=`, you can immediately continue with another operation
3. **Memory for Complex Calculations**: Use memory functions to store intermediate results
4. **History for Verification**: Check History to verify past calculations

### Common Patterns

**Calculate Total with Tax (15% tax)**:
1. Enter amount: `100`
2. Calculate tax: Tap `%`, `1`, `5`, `=` → Shows 15
3. Tap `M+` to store
4. Enter amount again: `1`, `0`, `0`
5. Tap `+`
6. Tap `MR` → Recalls 15
7. Tap `=` → Total: 115

**Average of Numbers**:
1. Add first number, tap `M+`
2. Add second number, tap `M+`
3. Add third number, tap `M+`
4. Tap `MR` to get sum
5. Divide by count: `÷`, `3`, `=`

### Scientific Calculator Pro Tips

1. **Trigonometry**: Remember inputs are in degrees
2. **Logarithms**: Use log for base-10, ln for natural log
3. **Powers of 10**: Use `1`, `0`, `x^y`, `n`, `=` for quick powers
4. **Square Roots Chain**: You can repeatedly tap √ for nested roots

### Best Practices

1. **Start Fresh**: Always use AC when starting a new calculation
2. **Verify**: Check History if you need to review a calculation
3. **Memory Safety**: Use MC (Memory Clear) when starting new memory-based calculations
4. **Decimal Precision**: The app shows up to 8 decimal places

## Troubleshooting

### Display Shows "Error"

**Cause**: Invalid operation (e.g., division by zero)
**Solution**: Tap AC and start over

### Number Too Long

**Issue**: Very large numbers may be displayed in scientific notation
**Solution**: This is normal for numbers beyond display capacity

### Widget Not Updating

**Solution**: 
1. Remove widget
2. Re-add widget from widget menu
3. Restart device if issue persists

### Theme Not Saving

**Solution**: 
1. Toggle theme again
2. Completely close and reopen app
3. Check device storage permissions
